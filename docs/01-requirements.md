| --- | --- |
| 版本 | v1.0.0 |

---

## 1. 背景与目标

### 1.1 背景

运营与市场团队需要在短信、海报、二维码等**字符数受限或需要埋点统计**的渠道投放链接。原始链接通常长达 100+ 字符，存在两个问题：

1. **长度问题**：短信按条计费，长链接占用大量字符额度；二维码密度过高导致扫描识别率下降。
2. **无数据**：无法知道某个链接被点击了多少次、有多少人点击。

### 1.2 目标

建设一个短链接服务，提供：

- 将任意长链接转换为 6 位短码，跳转 URL 形如 `http://host/{code}`。
- 记录并查询每个短链的访问量（PV）和独立访客数（UV）。
- 提供完整的链接生命周期管理能力（创建、查询、启用/禁用、删除、过期）。

### 1.3 成功度量

| 指标 | 目标值 |
| --- | --- |
| 跳转接口 P99 延迟（缓存命中） | < 50 ms |
| 跳转接口吞吐 | ≥ 1000 QPS（单实例，4C8G） |
| 短码长度 | 固定 6 位 |
| 短码不可枚举 | 无法通过连续性推断批量获取他人短链 |
| 跳转可用性 | 99.9%（Redis 故障时降级直查 DB，不整体不可用） |

## 2. 范围

### 2.1 范围内（v1.0.0）

- 用户注册、登录、令牌刷新
- 短链创建（自动短码 / 自定义短码）、设置过期时间
- 短链跳转与访问统计
- 短链管理（分页、搜索、启停、删除）
- 统计数据查询（PV/UV，按天）
- 接口限流
- 容器化部署

### 2.2 范围外（明确不做，避免范围蔓延）

以下项在 v1.0.0 **不实现**，但架构上预留扩展点：

| 项 | 原因 | 后续计划 |
| --- | --- | --- |
| 访问密码保护 | 需求优先级低 | v1.2 |
| IP 归属地解析 | 需引入离线 IP 库（数十 MB） | v1.3 |
| 自定义域名 / 短链前缀 | 需要域名备案与解析配置 | v2.0 |
| 链接批量导入导出 | 需求优先级低 | v1.2 |
| 用户注册邮箱验证 | 需要邮件服务依赖 | v2.0 |
| 多租户 / 团队协作 | 需要重构权限模型 | v2.0 |
| 布隆过滤器防穿透 | 当前空值缓存已够用 | 视压测结果决定 |

> **流程要点**：明确写出"不做什么"和"为什么不做"，比列出"要做什么"更能防止项目失控。范围外的每一项都应该有理由和去向，而不是简单砍掉。

## 3. 角色（Actor）

| 角色 | 说明 | 权限 |
| --- | --- | --- |
| 匿名访客 | 点击短链的普通用户 | 仅可访问跳转接口 |
| 注册用户 | 已登录的链接创建者 | 管理**自己**的短链，查看**自己**的统计 |
| 运维人员 | 部署与监控服务 | 访问 Actuator 健康与指标端点 |

v1.0.0 **不设管理员角色**——用户之间严格数据隔离，无跨用户操作。这是个有意的简化：管理员角色会带来一整套权限模型与审计需求，在用户量不足时是过度设计。

## 4. 用户故事与验收标准

> 每条用户故事都以「作为…我希望…以便…」表述，并附**可执行的验收标准（Acceptance Criteria）**。验收标准使用 Given-When-Then 格式，且必须能直接翻译为测试用例——写不出测试的验收标准是无效的。

### US-01 用户注册

**作为**一名新用户，**我希望**注册账号，**以便**使用短链管理功能。

**验收标准：**

- **AC-01.1** Given 用户名和邮箱均未被占用，When 提交合法的用户名/邮箱/密码，Then 返回 201，响应体包含用户 ID 与用户名，且**不包含密码或密码哈希**。
- **AC-01.2** Given 用户名已被占用，When 使用相同用户名注册，Then 返回 409，错误码 `USERNAME_TAKEN`。
- **AC-01.3** Given 邮箱已被占用，When 使用相同邮箱注册，Then 返回 409，错误码 `EMAIL_TAKEN`。
- **AC-01.4** Given 密码长度小于 8 位，When 提交注册，Then 返回 400，错误码 `VALIDATION_FAILED`，且响应中明确指出 `password` 字段不合法。
- **AC-01.5** Given 用户名包含非法字符（非 `[a-zA-Z0-9_-]`），When 提交注册，Then 返回 400，错误码 `VALIDATION_FAILED`。
- **AC-01.6** Given 注册成功，When 查询数据库该用户记录，Then 存储的密码为 BCrypt 哈希（以 `$2a$` 开头），**绝不可为明文**。

### US-02 用户登录

**作为**一名注册用户，**我希望**登录换取访问令牌，**以便**调用需要鉴权的接口。

**验收标准：**

- **AC-02.1** Given 用户名与密码均正确，When 提交登录，Then 返回 200，响应体包含 `accessToken`、`refreshToken` 及 `expiresIn`。
- **AC-02.2** Given 密码错误，When 提交登录，Then 返回 401，错误码 `INVALID_CREDENTIALS`。
- **AC-02.3** Given 用户名不存在，When 提交登录，Then 返回 401，错误码 `INVALID_CREDENTIALS`。
  > 注意：AC-02.2 与 AC-02.3 必须返回**完全相同**的错误码与文案，否则攻击者可据此枚举出系统内已存在的用户名。
- **AC-02.4** Given 用户已登录，When 携带 `accessToken` 访问 `GET /api/v1/users/me`，Then 返回 200 及当前用户信息。
- **AC-02.5** Given `accessToken` 已过期或签名被篡改，When 访问受保护接口，Then 返回 401，错误码 `TOKEN_INVALID`。
- **AC-02.6** Given 未携带任何令牌，When 访问受保护接口，Then 返回 401，错误码 `UNAUTHORIZED`。

### US-03 刷新令牌

**作为**一名登录用户，**我希望**在访问令牌过期后刷新，**以便**不必反复输入密码。

**验收标准：**

- **AC-03.1** Given 持有有效的 `refreshToken`，When 调用刷新接口，Then 返回 200 及**新的** `accessToken` 和 `refreshToken`。
- **AC-03.2** Given 持有有效的 `refreshToken`，When 刷新成功后，Then 旧的 `refreshToken` **立即失效**（一次性使用，防重放）。
- **AC-03.3** Given `refreshToken` 已被使用过，When 再次使用同一个令牌刷新，Then 返回 401，错误码 `TOKEN_INVALID`。
- **AC-03.4** Given 用户登出，When 再次使用登出前的 `refreshToken`，Then 返回 401。

### US-04 创建短链

**作为**一名登录用户，**我希望**把长链接转成短链，**以便**在字符受限的渠道投放。

**验收标准：**

- **AC-04.1** Given 已登录且提交合法的 `http(s)` 长链接，When 创建短链，Then 返回 201，响应体包含 6 位 `code` 与完整 `shortUrl`。
- **AC-04.2** Given 未指定 `customCode`，When 创建短链，Then 系统自动生成 6 位短码，且短码仅含 `[a-zA-Z0-9]`。
- **AC-04.3** Given 系统连续生成 10000 个短码，When 校验，Then **无一重复**。
- **AC-04.4** Given 系统生成的短码序列，When 尝试通过递推猜测下一个短码，Then 相邻短码之间**无可见规律**（不可枚举）。
- **AC-04.5** Given 指定了合法的 `customCode`（4–10 位，`[a-zA-Z0-9]`），When 创建短链，Then 使用该短码。
- **AC-04.6** Given 指定的 `customCode` 已被占用，When 创建短链，Then 返回 409，错误码 `CODE_TAKEN`。
- **AC-04.7** Given 指定的 `customCode` 为保留字（如 `api`、`admin`、`health`、`actuator`、`static`、`favicon`），When 创建短链，Then 返回 400，错误码 `CODE_RESERVED`。
- **AC-04.8** Given 指定的 `customCode` 长度或字符不合法，When 创建短链，Then 返回 400，错误码 `VALIDATION_FAILED`。
- **AC-04.9** Given 指定的 `originalUrl` 不是合法 URL 或协议不是 `http`/`https`，When 创建短链，Then 返回 400，错误码 `VALIDATION_FAILED`。
  > 协议白名单是**安全要求**，不是格式校验：放行 `javascript:` / `data:` 会让服务变成 XSS 与钓鱼的跳板。
- **AC-04.10** Given 指定了过去的 `expiresAt`，When 创建短链，Then 返回 400，错误码 `VALIDATION_FAILED`。
- **AC-04.11** Given 已登录用户 A 创建了短链，When 用户 B 尝试查询/修改/删除该短链，Then 返回 404（**不是 403**）。
  > 返回 404 而非 403，是为了不泄露「该短码存在但不属于你」这一信息。

### US-05 短链跳转

**作为**一名点击短链的访客，**我希望**被正确重定向到目标页面。

**验收标准：**

- **AC-05.1** Given 短码存在且状态为启用，When `GET /{code}`，Then 返回 **302** 且 `Location` 头为目标 URL。
- **AC-05.2** Given 短码不存在，When `GET /{code}`，Then 返回 404。
- **AC-05.3** Given 短码已过期（`expiresAt` 早于当前时间），When `GET /{code}`，Then 返回 410，错误码 `LINK_EXPIRED`。
- **AC-05.4** Given 短码已被禁用，When `GET /{code}`，Then 返回 403，错误码 `LINK_DISABLED`。
- **AC-05.5** Given 跳转成功，When 检查响应，Then **响应时间不包含统计写入的耗时**（统计必须异步化）。
- **AC-05.6** Given Redis 完全不可用，When 访问已存在的短码，Then 仍能正常返回 302（降级为直查数据库）。
- **AC-05.7** Given 同一短码被访问两次，When 查询该短链 PV，Then PV 为 2。

### US-06 短链管理

**作为**一名登录用户，**我希望**管理我的短链，**以便**随时调整投放策略。

**验收标准：**

- **AC-06.1** Given 已登录且拥有 25 条短链，When 请求 `GET /api/v1/links?page=0&size=10`，Then 返回 10 条记录，`totalElements` 为 25，`totalPages` 为 3。
- **AC-06.2** Given 已登录，When 分页查询短链，Then 结果**仅包含当前用户**的短链，且按创建时间倒序。
- **AC-06.3** Given 已登录，When 传入 `keyword` 参数，Then 结果中的 `originalUrl` 或 `code` 包含该关键字。
- **AC-06.4** Given 已登录且拥有该短链，When 调用禁用接口，Then 状态变为禁用，且此后跳转返回 403。
- **AC-06.5** Given 已登录且拥有该短链，When 调用启用接口，Then 状态变为启用，且此后跳转恢复 302。
- **AC-06.6** Given 已登录且拥有该短链，When 调用删除接口，Then 返回 204，且此后该短码跳转返回 404。
- **AC-06.7** Given 短链已被删除，When 再次用相同 `customCode` 创建，Then 创建成功（短码被释放）。
- **AC-06.8** Given 已登录，When `size` 参数传入 1000，Then 返回 400（`size` 上限 100）。
  > 无上限的分页参数是一个**拒绝服务漏洞**：`size=1000000` 会一次性拉爆内存。

### US-07 访问统计

**作为**一名登录用户，**我希望**查看短链的访问数据，**以便**评估投放效果。

**验收标准：**

- **AC-07.1** Given 某短链今天被访问 100 次（其中 30 个不同 IP），When 查询今日统计，Then PV 为 100，UV 为 30±1（HyperLogLog 误差范围内）。
- **AC-07.2** Given 查询统计，When 传入 `days=7`，Then 返回最近 7 天的按天数据，**包含访问量为 0 的日期**（补零）。
  > 前端画折线图时缺日期会导致 X 轴断裂，补零是**服务端**的职责。
- **AC-07.3** Given 统计已写入 Redis 但尚未刷入数据库，When 在 60 秒内查询统计，Then **仍能看到最新数据**（读取时合并 Redis 增量）。
- **AC-07.4** Given 已登录用户 A，When 查询用户 B 的短链统计，Then 返回 404。
- **AC-07.5** Given `days` 传入 0 或 400，When 查询统计，Then 返回 400，错误码 `VALIDATION_FAILED`。

### US-08 接口限流

**作为**一名运维人员，**我希望**服务能自我保护，**以便**在异常流量下不雪崩。

**验收标准：**

- **AC-08.1** Given 同一 IP 在 1 分钟内请求跳转接口超过 300 次，When 继续请求，Then 返回 429，错误码 `RATE_LIMITED`，且响应含 `Retry-After` 头。
- **AC-08.2** Given 同一用户 1 分钟内创建短链超过 30 次，When 继续创建，Then 返回 429。
- **AC-08.3** Given 被限流，When 等待限流窗口结束后重试，Then 请求恢复正常。

### US-09 可观测性

**作为**一名运维人员，**我希望**了解服务运行状态。

**验收标准：**

- **AC-09.1** Given 服务正常运行，When 请求 `/actuator/health`，Then 返回 200 且 `status` 为 `UP`；当 MySQL 或 Redis 不可用时，返回 503 且明确指出是哪个组件不可用。
- **AC-09.2** Given 服务已处理若干请求，When 请求 `/actuator/prometheus`，Then 输出包含 HTTP 请求耗时直方图与 JVM 指标。
- **AC-09.3** Given 任意请求完成，When 查看日志，Then 日志中包含 `traceId`，可据此串起该请求的所有日志。
- **AC-09.4** Given Actuator 端点，When 匿名访问，Then **仅** `/actuator/health` 可访问，其余端点返回 401。
  > Actuator 端点是**信息泄露重灾区**：`/actuator/env`、`/actuator/beans` 会暴露配置与内部结构。

## 5. 非功能需求

| 类别 | 需求 | 验证方式 |
| --- | --- | --- |
| 性能 | 跳转接口缓存命中 P99 < 50 ms | 压测（JMeter/wrk） |
| 性能 | 单实例支持 1000 QPS 跳转 | 压测 |
| 可用性 | Redis 故障时跳转降级可用，不影响核心链路 | 集成测试中停掉 Redis 验证 |
| 一致性 | 统计允许**最终一致**，延迟 ≤ 60 s；核心链接数据必须**强一致** | 定时任务周期即延迟上限 |
| 安全 | 密码 BCrypt(cost=10) 存储，绝不明文 | 集成测试断言哈希前缀 |
| 安全 | 短码不可枚举 | 单元测试验证打散效果 |
| 安全 | 用户数据严格隔离 | 集成测试跨用户访问 |
| 安全 | 跳转协议白名单 `http`/`https` | 单元测试注入 `javascript:` |
| 安全 | 限流保护跳转与创建接口 | 集成测试 |
| 可维护性 | 单元测试行覆盖率 ≥ 70% | JaCoCo 报告 |
| 可维护性 | 核心业务逻辑（短码生成、跳转决策）覆盖率 ≥ 90% | JaCoCo 报告 |
| 可移植性 | 一条 `docker compose up` 启动完整环境 | 部署验证 |

> **流程要点**：每条非功能需求都必须绑定**验证方式**。写不出验证方式的指标（例如"系统要快"）不是需求，是愿望。

## 6. 数据一致性约定

| 数据 | 一致性级别 | 说明 |
| --- | --- | --- |
| 用户账号 | 强一致 | 唯一约束由数据库保证 |
| 短链记录 | 强一致 | 短码唯一约束由数据库保证，不依赖应用层判断 |
| 短链缓存 | 最终一致 | Cache-Aside，更新时删除缓存，容忍短暂窗口 |
| 访问统计 | 最终一致 | Redis 计数 + 定时刷库，延迟上限 = 刷库周期 |

> 短码唯一性**必须**由数据库唯一索引保证，而非"先查询再插入"。后者在并发下必然产生重复数据——这是生产事故的经典成因，也是本项目集成测试的必测项。

## 7. 错误码清单

| HTTP | 错误码 | 含义 |
| --- | --- | --- |
| 400 | `VALIDATION_FAILED` | 参数校验失败，`details` 中给出字段级原因 |
| 400 | `CODE_RESERVED` | 自定义短码为保留字 |
| 400 | `INVALID_URL` | URL 格式不合法或协议不在白名单 |
| 401 | `UNAUTHORIZED` | 未提供凭证 |
| 401 | `INVALID_CREDENTIALS` | 用户名或密码错误 |
| 401 | `TOKEN_INVALID` | 令牌无效、过期或已被使用 |
| 403 | `LINK_DISABLED` | 短链已被禁用 |
| 403 | `FORBIDDEN` | 无权访问该资源 |
| 404 | `NOT_FOUND` | 资源不存在（含跨用户访问他人资源） |
| 409 | `USERNAME_TAKEN` | 用户名已存在 |
| 409 | `EMAIL_TAKEN` | 邮箱已存在 |
| 409 | `CODE_TAKEN` | 短码已被占用 |
| 410 | `LINK_EXPIRED` | 短链已过期 |
| 429 | `RATE_LIMITED` | 请求过于频繁 |
| 500 | `INTERNAL_ERROR` | 服务内部错误（对外不暴露堆栈） |
